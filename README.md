# Workshop Inventory Manager (Система учета инвентаря мастерской)

Консольное приложение на Python для автоматизации учета инструментов, расходных материалов, фиксации их выдачи сотрудникам и контроля дефицита[cite: 2, 8].

Проект разработан в качестве итоговой работы по курсу «Python и основы CS»[cite: 1, 2].

---

## 📌 Назначение и решаемая проблема

В мастерских и сервисных центрах учет инструментов и материалов часто ведут вручную, что приводит к утере оборудования, перерасходу бюджета и отсутствию ответственности за выданные вещи[cite: 8]. 

**Workshop Inventory Manager** решает эти задачи:
* Ведет централизованный каталог инвентаря и расходных материалов[cite: 2, 8].
* Регистрирует выдачу и возврат инструментов сотрудникам[cite: 2, 8].
* Автоматически отслеживает позиции с критическим остатком (дефицит)[cite: 8].
* Ведет очередь неотложных заявок на закупку и ремонт[cite: 6, 8].
